# Changelog

All notable changes to Z-Stack Cell Counter will be documented in this file.

The project uses semantic versioning: major.minor.patch.

## [Unreleased]

### Planned

- Additional study-profile examples
- Automated tests for image loading, filename parsing, and exports
- Simplified installation and packaging

## [0.1.0] - 2026-08-17

### Added

- Manual four-class cell annotation in napari
- Multi-channel microscopy Z-stack display
- Sampled percentile-based display normalization
- XY-only average downsampling
- Target placement, undo, and click-to-erase workflow
- Subtle counting-grid reference
- Image and subject-aware navigation
- Resume at the first unreviewed image
- Explicit image-completion and deferred-review states
- Navigation warning for unfinished images
- Automatic session recovery
- Dataset-wide and per-subject structured exports
- Missing, duplicate, unexpected, flagged, and unreviewed-image QC
- Activity logging
- Optional JSON filename-metadata profiles
- mPFC SYN study profile
- Software-version recording in generated results
